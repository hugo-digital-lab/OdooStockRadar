# Odoo 庫存雷達（庫存變動監看小工具）

每 30 分鐘自動比對 Odoo 兩倉庫存（享物總倉＋禾洛智能雲倉），有變動時右下角跳通知。

## 安裝（同事適用）
1. 下載整包檔案（綠色 Code 按鈕 → Download ZIP，解壓縮）
2. 放到 `D:\OdooStockRadar`（路徑不要有空白）
3. 編輯 `config.json`：填入 Odoo 網址 / db / 帳號 / API key（找 Hugo 拿）
4. 雙擊 `setup.bat` → 完成（自動註冊每 30 分鐘掃描＋開機自啟）

## 使用
- 右下角青色圖示：點兩下開啟雷達視窗（歷史明細＋搜尋＋在途庫存）
- 右鍵選單：立即檢查一次 / 🔍 檢查更新 / 結束常駐

## 更新
托盤右鍵 → 🔍 檢查更新（手動制，不會自動檢查）；或按視窗頂部 ⤓ 檢查更新

## 移除
雙擊 `remove.bat`（資料資料夾 data\ 會保留）
